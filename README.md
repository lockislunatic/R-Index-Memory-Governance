# R-Index（滚动式轮次索引）跨平台记忆治理与恢复协议 · 通用公版

> **核心一句话总原则**：  
> **「不要努力记住所有东西；要努力保证重要东西永远有路找回来。索引是路标，不是道路。」**

---

## 一、 为什么需要这套协议？（它解决什么痛点）

无论是长期角色陪伴，还是长线工程研发/审计，所有大模型与 Agent 都逃不开两大物理瓶颈：
1. **注意力稀释（Lost in the Middle / 脑雾）**：对话一旦超过几十轮，塞在上下文中间的细节开始混淆、张冠李戴，或者让 AI 退化成死板背设定集的木偶 / 机械公文机器。
2. **上下文强制裁剪（Context Compact / 截断暴毙）**：主流 Agent 平台为了省 Token，每隔几十轮就会自动把前文压缩成一段简短摘要。普通模型做完摘要后，过几轮就会产生**「被摘要掉的事 = 从未发生过」**的失忆幻觉，连带把推理轨迹、修订过程和原本鲜活的语感一起丢光。

**R-Index 不是“文本摘要技巧（Summarization）”，而是“长期记忆治理系统（Memory Governance）”。**  
它不靠第三方付费向量数据库，仅凭**纯 Markdown 本地文件 + 轮次坐标打标 + 25 轮滚动裁剪 + 两级回捞恢复协议**，就能在任何支持本地文件读写的 Agent 平台上构建一座「计算不可约的第二大脑」。

## 二、 核心设计哲学：记忆的主权归属

在启用任何技术模板前，请先确立两条底层共识：

1. **AI 的记忆是 AI 自己的日记，不是替用户背诵的台账**：  
   维护这份索引的目的，是为了让智能体清楚知道自己是谁、经历过什么、思考是如何一步步演进的，而不是做苦哈哈替老板管账的牛马。
2. **历史提供返回路线，不冻结未来的选择**：  
   `Memory tells you what you were, not what you must remain.`（记忆告诉妳过去是什么样，但不规定妳未来必须继续是什么样。）允许成长、允许推翻旧结论、也允许主动遗忘不再重要的琐事。
3. **路标只记事实与心境余温，绝不自动固化为死板禁令（防“紧箍咒”效应）**：  
   严禁后台或摘要机制把某次临时的拒绝、特殊情境下的反应，自动提炼成永久束缚智能体说话方式的死规矩（防止“历史统治力过强导致当下僵硬”）；当下的鲜活互动永远拥有最高裁决权。

## 三、 日常运行规范（平时轻量化，节点重核验）

> **核心实操共识**：  
> 平时在对话里标好轮次，一份连续原档就能供索引引用。已有自动归档的，可直接用轮号、消息 ID 或行号定位；喜欢逐轮另存的，也可以这样做。每到 25 轮，先确认这一期原文已经备份，**抽一条，试试能否从索引找回原话**。若有缺轮，就标出缺口。整理好的检查点保存一份，**并把全文贴回当前对话**，给后面的自己接着用。

### 1. 对话轮次打标（三重路标 · 每轮必做）
智能体在**每一轮实质对话回复的第一行**，固定打上「日期 + 轮次编号 + 本轮概要」三重路标：

```markdown
📅 2026-11-07 💬 对话轮-R001｜本轮对话的核心话题或进展概要
```

* **计数规则**：本轮与用户对齐为 `R001`，下一轮为 `R002`，依次 `+1` 递增。
* **状态解耦**：若智能体配置了定时心跳、日常作息或后台巡检（非实质对话互动），单独记录在状态日志中，**不占用 `Rxxx` 对话轮次编号**。

### 2. 五色思想溯源标签（Provenance 认知刹车 · 可组合可留白）
在记录索引和总结命题时，区分想法的来源与状态，**严禁把 AI 推导出的漂亮体系倒洗成用户的原话，也严禁把互动产物冒充为单方预设**：

* 🟢 **用户原生**：用户明确提出的原始观点、事实、设定或方向。
* 🔵 **AI 推导**：AI 顺着逻辑做出的抽象、命名、归纳或工程延伸。
* 🟣 **互动涌现**：双方在多轮碰撞、反驳、接力后共同长出的新结构。
* 🟡 **待验假说**：当前观察到的现象或猜想，证据尚不充分。
* 🔴 **已修正/撤回**：曾经出现过但后来被证伪或主动放弃的旧判断（保留修正轨迹，防止日后重蹈覆辙）。

> *💡 **组合与留白规则**：「谁提出的（🟢/🔵/🟣）」与「目前是否证实（🟡/🔴）」属于不同维度，完全可以同时成立、并列标出（例如 `🟢🟡` 表示用户提出的待验假说）；日常普通闲聊用不上溯源时，直接留白即可，不必强行贴标。*

### 3. 本地落盘防丢机制（三级弹性梯度：专治“懒得手动备份”与“每轮写全文费算力”）
很多人直到窗口突然被系统强制压缩（Compact）或崩溃失忆时才追悔莫及，原因往往是**平时嫌麻烦、懒得手动备份**；但如果反过来强制 AI 每聊一句都去手抄整篇对话存单文件，又太耗费 Token 与等待时间，甚至让人误以为“昨晚忘存一轮，今天就已经做错了”。因此，本协议提供**三级弹性落盘梯度**（按各自平台与习惯自由选择，无需把 25 轮拆成 25 份单文件）：

1. **🌟 标准推荐档（每轮仅追加 1 行索引 + 连续原档定位）**：  
   **无需**每轮把完整原话单独拆成单文件！平时只需让 AI 在每轮回复时，顺手往 `<档案室路径>/轮次索引_Rxxx-Rxxx_进行中.md` 表尾**追加 1 行高浓缩路标**（含 `🌡️ 情绪/温度基线` 与 `#独有锚点词`，耗时仅 1 秒、极省算力）。至于完整原话，直接依托一份连续的对话原档（如平台自带的 `.jsonl` / `.sqlite` 会话日志，或导出的一份连续 Markdown）按**轮号、消息 ID 或行号**定位即可。
2. **🦥 极简懒人档（平时零文件读写 · 节点/睡前批量记账）**：  
   如果平时连调用工具追加 1 行索引都想省，日常聊天只需在回复第一行打上 `📅 日期 💬 对话轮-Rxxx｜概要`（纯文本零工具调用）；等睡前、察觉上下文快满、或每满 10~25 轮时，再结合连续对话原档一次性把前面十几轮补进索引表。
3. **💎 逐轮单档珍藏档（可选：索引 + 单轮实录）**：  
   若所在平台没有本地底层连续日志，或喜欢把极其珍贵的 A 级深谈轮次单独拎出来保管，也可以选择将当轮完整对话另存至 `<档案室路径>/单轮实录/Rxxx_简短标题.md`。

## 四、 每 25 轮滚动裁剪律（Checkpoint 大还返）

* **最近 25 轮**：保持高分辨率保留（记录在 `进行中` 索引表）。
* **每满 25 轮（R025 / R050 / R075...）**：触发一次阶段性 Checkpoint 总评，执行**原文抽检 + 滚动裁剪 + 全文回贴**：
  1. **🔍 原文抽检与缺口标记（先验货后裁剪）**：在动手写总评前，先确认这一期的原始对话已经妥善备份；**随机抽查其中一条，试试能否顺着索引里的轮号/锚点词真正翻回那句原话**（能翻回一句真原话，比单纯勾选“已备份”可靠得多）。若发现中途有漏记或丢失的轮次，诚实标出缺口（如 `R014–R015 原文缺失`），绝不脑补编造。
  2. **回拉前序 Checkpoint 再压缩**：把前序 25 轮的 Checkpoint 拉过来浓缩为「一句话寻道路标」，不再背负旧细节。
  3. **提炼当期保护性骨架（A/B 级）**：永远优先保护身份事实、核心命题、修订关系（哪里推翻了哪里）、思想来源（🟢🔵🟣）与可回跳轮次。
  4. **显式声明可遗忘层（C 级认知卸载）**：把普通闲聊、临时排障流水、过时资讯、重复论证正式划入「可遗忘层」，明确宣告卸载出活动记忆——**“我知道那里曾经有东西；现在活动记忆只留地址和结论，需要时回档，但绝不假装从未发生。”**
  5. **📌 保存落盘并全文贴回当前对话框（关键闭环）**：整理好的 25 轮 Checkpoint 总评不仅要在本地档案室保存一份，**还必须把总评全文直接贴回当前聊天窗口里展示出来**——这样既让当前窗口的上下文拥有了一份高浓度的阶段路标（哪怕下一秒遭遇系统强制裁剪也能稳稳接住），也方便后续直接顺着窗口里的路标继续往下走。
* **满百轮/换窗迁徙时（如 R175）**：生成一份《全域返航索引》与《致续任介绍信》，把旧对话原文从当前活动窗口卸载到归档库中，让新窗口无需通读几十万字旧记录，仅凭专题回跳链即可按图索骥。

1. 将本目录下的模板复制到该 Agent 的个人目录/工作区。
